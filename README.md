# Pixel Canvas App

A creative pixel canvas web application. Draw, create, and express yourself with pixels!

## Features

- Interactive pixel canvas
- Color palette
- Drawing tools
- Save and load creations

## Quick Start

```bash
# Install dependencies
npm install

# Run the application
npm start

# Open in browser
http://localhost:3000
```

## Project Structure

```
mee.ai/

├── server.js           # Node.js server
```
